# 📌 Problem Statement

You are given `n` versions `[1,2,3...n]` of a product.

After a certain version becomes bad, all versions after it are also bad.

You are provided an API:

```js
isBadVersion(version)
```

which returns:

- `true` → bad version
- `false` → good version

Find the first bad version while minimizing API calls.

---

# 🧠 Intuition

The versions follow a sorted pattern:

```text
Good Good Good Bad Bad Bad
```

Since the array is monotonic, Binary Search is the optimal solution.

---

# 🔍 Approach

1. Apply Binary Search from `1` to `n`
2. Find the middle version
3. If middle version is bad:
   - store it as answer
   - search on left side
4. Else:
   - search on right side
5. Return the stored answer

---

# 📈 Dry Run

## Input

```text
n = 5
bad = 4
```

## Steps

```text
mid = 3 → false
Search Right

mid = 4 → true
Store Answer = 4
Search Left
```

✅ First Bad Version = `4`

---

# ✅ JavaScript Code

```js
/**
 * Definition for isBadVersion()
 * 
 * @param {integer} version number
 * @return {boolean} whether the version is bad
 * isBadVersion = function(version) {
 *     ...
 * };
 */

/**
 * @param {function} isBadVersion()
 * @return {function}
 */
var solution = function(isBadVersion) {

    return function(n) {

        let st = 1;
        let end = n;
        let num = 0;

        while (st <= end) {

            let mid = Math.floor((st + end) / 2);

            let value = isBadVersion(mid);

            if (value === false) {
                st = mid + 1;
            } 
            else {
                num = mid;
                end = mid - 1;
            }
        }

        return num;
    };
};
```
