# 🔍 What is Binary Search?

Binary Search is a searching algorithm used to find a target element in a **sorted array**.

Instead of checking every element one by one, Binary Search keeps dividing the array into half, making it super fast.

📌 Important:
- Array **must be sorted**
- Works in **O(log n)** time complexity

---

# 🧠 Intuition

This is a basic Binary Search problem where we need to find the target element from the given sorted array.

The main idea is:

- Find the middle element
- Compare it with the target
- If target is bigger → search in right half
- If target is smaller → search in left half
- Repeat until target is found

---

# ⚙️ Approach

## Step 1: Initialize Start & End

We take two pointers:

```js
let st = 0;
let end = nums.length - 1;
```

- `st` → starting index
- `end` → last index of array

---

## Step 2: Entry Condition

We run loop until start becomes greater than end.

```js
while(st <= end)
```

This means our search space is still valid.

---

## Step 3: Find Middle Element

```js
let mid = Math.floor((st + end) / 2);
```

We use `Math.floor()` because array indexes should be integers.

---

# 🎯 Compare Mid with Target

We check 3 conditions:

```js
if(nums[mid] === target)
```

✅ If equal → target found

---

```js
if(nums[mid] > target)
```

📉 If mid value is bigger than target,
we search in the **left half**

```js
end = mid - 1;
```

---

```js
else
```

📈 If mid value is smaller than target,
we search in the **right half**

```js
st = mid + 1;
```

## Time Complexity


## Space Complexity


# 💻 JavaScript Code

```js
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number}
 */
var search = function(nums, target) {

    let st = 0;
    let end = nums.length - 1;

    while(st <= end){

        let mid = Math.floor((st + end) / 2);

        if(nums[mid] === target) return mid;

        if(nums[mid] > target){
            end = mid - 1;
        }
        else{
            st = mid + 1;
        }
    }

    return -1;
};
```

# 🌟 Key Points to Remember

✅ Binary Search only works on **sorted arrays**  
✅ Every iteration removes half of the array  
✅ Much faster than Linear Search  
✅ Very common in interviews and coding rounds
